Cara upload ke GitHub Pages:
1. Ekstrak ZIP ini.
2. Buat repository baru di GitHub.
3. Upload index.html dan folder assets secara utuh ke repository.
4. Buka Settings > Pages.
5. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
6. Tunggu hingga tautan GitHub Pages muncul.

Tombol lagu membuka pencarian Best Part di Spotify. Pengunjung perlu menekan tombol untuk mendengarkan.
Jangan pisahkan atau ubah nama file dalam folder assets.
